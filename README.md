# M.I.L.O. — My Intelligent Life Operator

M.I.L.O. es un asistente digital personal y el centro de operaciones de una agencia de programación. El objetivo es construir un sistema funcional, modular y verificable; no un chatbot con apariencia futurista.

## Principios

- Funcionalidad real antes que apariencia.
- Interfaz adaptativa: la experiencia cambia según la tarea; los menús permanentes no son protagonistas.
- No crear un dashboard genérico ni controles decorativos o datos simulados.
- No declarar una capacidad terminada sin probarla.
- Arquitectura modular y proveedores intercambiables.
- Memoria persistente y separación estricta de datos por cliente/proyecto.
- Autonomía dentro de permisos explícitos.
- Seguridad, trazabilidad, límites de gasto y posibilidad de detener procesos.
- Construcción incremental: un módulo probado antes de iniciar el siguiente.
